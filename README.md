# Pipeline de Vendas

Olá. Estou desenvolvendo um projeto de CRM Comercial no SUPABASE

Gostaria que você criasse um código com base nas informações a seguir. Para isso, leia as seguintes informações: Nome do Lead, Empresa do Lead, Valor do Projeto, Etapa do Comércio (Novo, Em Contato, Fechado). Para lê-las, observe a tabela na imagem anexada nesta mensagem.

1 - Gostaria que listasse os LEADS da tabela, realizando um código em que torna capaz a leitura dos leads na tabela. Além disso, gostaria que houvesse a opção de um formulário para adicionar mais um lead. Por último, a criação de um seletor que torna capaz a mudança de etapas do comércio (novo, em contato, fechado.)
